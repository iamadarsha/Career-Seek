# Pipeline, Documents, And Notifications

## Pipeline

Pipeline is the local CRM for applications.

It supports:

- saved jobs
- preparing
- applied
- follow-up due
- recruiter replied
- interview scheduled
- interviewed
- assessment
- offer
- rejected
- archived

Application state changes create timeline events.

## Saved

Saved shows jobs explicitly parked for later. These are canonical application records with status `saved`.

## Applied

Applied shows submitted jobs with application dates and source links. These records are shared with Pipeline and dashboard cards.

## Documents

Documents shows:

- uploaded base resumes
- tailored resume versions
- cover letter versions
- outreach notes
- ATS reports when available

Generated assets are linked to scored jobs and local files where a file exists.

## Notifications

Notifications is the recovery rail for:

- due reminders
- stale follow-ups
- scan outcomes
- automation outcomes

The page supports refresh, mark-read, mark-all-read, archive, and action links.

## AI Coach

AI Coach uses indexed local materials and Gemini to answer grounded questions about:

- the user profile
- resume content
- selected jobs
- generated documents
- interview preparation

## Analytics

Analytics summarizes:

- funnel counts
- portal performance
- document generation
- stale opportunities
- weekly review
- experiments
- recent activity
