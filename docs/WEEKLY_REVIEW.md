# Weekly Review Service

## Location

`src/lib/services/analytics/weekly-review-service.ts`

## Week Bounds

- Start: Monday 00:00:00 local time
- End: Sunday 23:59:59 local time
- `weekStart` is the canonical key used for upsert deduplication

## Functions

```ts
computeWeeklyReview(weekStart?: Date): Promise<WeeklyReview>
saveWeeklyReview(review: WeeklyReview): Promise<void>
getLatestWeeklyReview(): Promise<WeeklyReview | null>
```

`computeWeeklyReview()` defaults to the current week when called with no argument. Pass an explicit `weekStart` (any Monday) to recompute historical weeks.

`saveWeeklyReview()` upserts into `weekly_reviews` keyed on `weekStart`. Calling it multiple times in the same week overwrites the previous record.

`getLatestWeeklyReview()` fetches the most recent row ordered by `weekStart DESC` and deserializes `metricsJson` and `actionsJson` back into typed objects.

## Computed Metrics

All metrics are scoped to `[weekStart, weekEnd]` unless noted.

| Field | Description |
|---|---|
| `jobsDiscovered` | Count of `scored_jobs` rows created this week |
| `newTierAOpportunities` | Count of `scored_jobs` where `tier = 'A'` created this week |
| `applicationsSubmitted` | Count of applications with `submittedAt` in this week |
| `followUpsCompleted` | Count of follow-up activities marked complete this week |
| `followUpsMissed` | Count of follow-up activities with `dueDate` in this week and `completedAt IS NULL` |
| `interviewsScheduled` | Count of jobs reaching `interview_scheduled` status this week |
| `offersReceived` | Count of jobs reaching `offer_received` status this week |
| `rejections` | Count of applications moved to `rejected` status this week |

## Derived Fields

```ts
type WeeklyReview = {
  weekStart: Date
  weekEnd: Date
  metrics: WeeklyMetrics          // 8 fields above
  bestPortal: string | null       // portal with highest application count this week
  topInsights: InsightItem[]      // up to 3 non-dismissed insights, highest severity first
  staleCount: number              // jobs in saved/prepared with no activity for 14+ days
  lostOpportunities: number       // jobs that moved to rejected/ghosted this week
  suggestedActions: string[]      // plain-text action strings generated from metrics
  computedAt: Date
}
```

## Suggested Actions Logic

`suggestedActions` is a string array generated by simple threshold checks after metrics are computed:

- If `followUpsMissed > 2` → add follow-up reminder action
- If `newTierAOpportunities > 0 && applicationsSubmitted === 0` → add apply-to-tier-a action
- If `staleCount > 3` → add clear-stale-pipeline action
- If `jobsDiscovered < 5` → add expand-search-profile action

## Serialization

`metricsJson` and `actionsJson` are stored as JSON strings in SQLite. `getLatestWeeklyReview()` calls `JSON.parse` on both fields and casts to the appropriate types before returning.
